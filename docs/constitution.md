# Kiln MCP constitution

## Mission

Kiln MCP makes WordPress development fast and agent-friendly without requiring a commercial intermediary or turning a site into an unrestricted remote-control surface.

## Governing principles

1. Self-hosted by default. The plugin has a complete no-cost operation path on ordinary WordPress hosting. An optional relay must be independently deployable and FLOSS.
2. Security is a feature. Policy, authorization, validation, approval, auditability, and safe failure are product requirements.
3. Capabilities over escape hatches. Model-facing tools are small, named domain operations with exact schemas, preconditions, effects, and redacted receipts.
4. Local first and private. Telemetry is disabled. Network operations are opt-in and disclosed.
5. Stable contracts. Public tool contracts are versioned, schema-tested, and accompanied by migration/rollback plans.
6. Evidence before claims. Every requirement maps to automated validation and, where appropriate, reproducible manual acceptance.
7. No ungoverned automation. A model request is intent, not authority.

## Quality gates

No milestone is complete until requirements, architecture, threat model, traceability, tests, manual acceptance, and release notes agree. Failing quality gates must be fixed, never bypassed.
